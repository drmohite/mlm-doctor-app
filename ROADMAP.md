# 💡 MLM Doctor - Ideas for Future Improvements

Here is a list of features and enhancements planned for future iterations of MLM Doctor:

*   **Go-to-Definition**: Enable cross-referencing so clicking a `CALL MLM_NAME` statement instantly jumps to that corresponding `.mlm` file in the workspace.
*   **Diff View**: Implement a split-pane comparison view to compare the current version of an MLM against a saved backup or its previous state.
*   **New MLM Wizard**: Scaffold a new MLM from a standardized template using prompts or an interactive wizard to quickly generate the basic structure.
*   **Export Report**: Generate professional PDF or HTML summaries containing variables, SQL blocks, and logical flows for clinical sign-off and auditing.
