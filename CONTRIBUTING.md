# Contributing to MLM Doctor

Thanks for your interest in contributing to MLM Doctor.

## How to Contribute

- Fork the repository and create a feature branch.
- Keep changes focused and scoped to one concern per pull request.
- Add or update documentation when behavior changes.
- Test your changes locally before opening a pull request.

## Development Setup

1. Clone the repository.
2. Run the app using a local HTTP server.
3. Open the app in a Chromium-based browser.

## Pull Request Guidelines

- Use clear, descriptive commit messages.
- Explain the problem, the approach, and any trade-offs.
- Include screenshots for UI changes.
- Reference related issues where applicable.
- Follow `.github/pull_request_template.md`.

## Code Quality Expectations

- Preserve offline-first behavior.
- Avoid introducing fake data or fallback-only logic.
- Keep the Arden Syntax editing experience stable and predictable.
- Update `README.md` or related docs for user-visible changes.
- Add/update entries in `CHANGELOG.md` for release-relevant changes.

## Reporting Bugs

Open an issue with:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Browser and OS details

Use issue templates in `.github/ISSUE_TEMPLATE/` for bug reports and feature requests.
